Pipeline

End-to-end workflow
  1. Cleaning: dedupe, fix geocoding, type and domain checks, per-city 3×IQR outlier fence
  2. Feature engineering: log distances, guests/bedroom, attraction×restaurant, quality score, weekend flag
  3. Leakage-safe split: grouped by listing (weekday and weekend rows stay together)
  4. Models: Ridge, Random Forest, LightGBM, XGBoost, CatBoost (early stopping)
  5. Ensemble: weights optimised on a grouped validation fold
  6. Serving: refit on 100% data, location features derived from nearest listings, SHAP explanations
